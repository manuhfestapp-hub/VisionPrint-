# VisionPrint

AI vision board printing app (base44 project).

This repository is synced with base44 for two-way GitHub sync.

## GitHub Repository

**https://github.com/manuhfestapp-hub/VisionPrint-**

## How to Contribute

1. Clone the repo:
   ```bash
   git clone https://github.com/manuhfestapp-hub/VisionPrint-.git
   cd VisionPrint-
   ```

2. Start the dev environment:
   ```bash
   docker compose -f docker-compose.base44.yml up -d --build
   ```

3. The app runs on `http://localhost:3000`.

4. Make your changes on a feature branch, then open a pull request against `main`.
